لتشغيل المشروع، ستحتاج إلى تشغيل كل من الواجهة الخلفية (Backend - .NET) والواجهة الأمامية (Frontend - Next.js) بشكل منفصل في نافذتين (Terminals) مختلفتين.

إليك الخطوات بالتفصيل:

1. تشغيل الواجهة الخلفية (Backend)
افتح نافذة Terminal جديدة (أو موجه الأوامر CMD / PowerShell) وقم بتنفيذ الأوامر التالية:

انتقل إلى مجلد الـ API:
bash
cd c:\Users\kemo\Downloads\ushers.eg\backend\src\UshersEg.API
قم بتشغيل المشروع:
bash
dotnet run
(ملاحظة: يمكنك استخدام dotnet watch run إذا كنت تريد أن يتم إعادة تشغيل السيرفر تلقائياً عند إجراء أي تعديل في الكود. كما يمكنك فتح ملف UsherHub.slnx الموجود في مجلد الـ backend باستخدام Visual Studio والضغط على زر التشغيل).

2. تشغيل الواجهة الأمامية (Frontend)
افتح نافذة Terminal أخرى (مختلفة عن الأولى) وقم بتنفيذ الأوامر التالية:

انتقل إلى مجلد الـ Frontend:
bash
cd c:\Users\kemo\Downloads\ushers.eg\frontend
تثبيت الحزم (إذا لم تقم بتثبيتها مسبقاً):
bash
npm install
تشغيل المشروع:
bash
npm run dev
بعد ذلك سيظهر لك رابط في الـ Terminal (غالباً سيكون http://localhost:3000)، يمكنك فتحه في المتصفح لرؤية الموقع يعمل أمامك.

ملاحظة أخيرة: تأكد من أن السيرفر الخاص بقاعدة البيانات (SQL Server) يعمل بشكل سليم على جهازك لكي يعمل الـ Backend بدون مشاكل.
